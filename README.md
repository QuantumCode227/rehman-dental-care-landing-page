# REHMAN DENTAL CARE — LANDING PAGE

## Setup & Deployment

1. Open `index.html`.

2. Search for comments containing **"CHANGE"**.

3. Replace the dummy values:

   - **LOGO IMAGE URL**
   - **PHONE NUMBER**
   - **WHATSAPP LINK**
   - **GOOGLE MAPS LINK**
   - **ADDRESS**
   - **TIMINGS**
   - **EMAIL**
   - **INSTAGRAM LINK**
   - **FACEBOOK LINK**
   - **GOOGLE REVIEW LINK**

4. Open `index.html` in a browser and test everything.

5. When everything is correct, upload the folder/repository to **GitHub** and connect the repository to **Cloudflare Pages**.

> **IMPORTANT:**  
> The QR code should only be generated **AFTER** the final production Cloudflare Pages URL is confirmed.
